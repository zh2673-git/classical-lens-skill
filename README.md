# classical-lens

以中国与西方 **39 套传统思想体系**为透镜，审视任何一个问题、决定或事物。

核心主张：**多视角不是为了周全，是为了暴露前提。**

---

## 这是什么

你拿一个问题来（"要不要定这条规矩"、"该不该辞职"、"为什么我明明知道却做不到"），本技能会：

1. **按问题类型选镜** —— 不从"我知道哪些哲学家"出发，从"这个问题需要哪种追问"出发。
2. **输出多视角总纲表** —— 2-3 副主镜 + 1-2 副异类镜，每副给出：它会先问什么、照见什么、**对本问题给出什么判断**、在本题上漏掉什么、置信度。
3. **必须呈现真冲突** —— 至少一对给出**相反且不可调和**答案的透镜，并写明它们分歧的前提。不许写"各有道理、应当结合"。
4. **指出各镜共同的盲区** —— 所有选中的透镜都照不到的地方。这是"多视角"最容易被漏掉的一格。
5. **给收敛选项** —— 如果只能取一副，取哪副、为什么、代价是什么。

你也可以指定一副镜深入："就从庄子说"、"用福柯看"——此时走**七步深潜**：锁镜 → 原典依据 → 方法逐步落到本题 → 判断 → 盲区 → 与谁对立 → 什么会推翻这个判断。

## 39 套体系，七个类别

分类轴不是按朝代或国别，而是按**它把什么当作首要的**——因为用户关心"哪副镜子照得出这个"，不关心"这是宋代的还是希腊的"。

| 类 | 追问 | 体系 |
|---|---|---|
| **G** 生成 | 万物从哪来、按什么律运行 | 老子、庄子、阴阳家、易传、阿奎那 |
| **R** 人伦 | 人在什么位置、该如何相处 | 孔子、孟子、荀子、墨家、斯多葛、伊壁鸠鲁、康德、存在主义 |
| **Z** 治道 | 谁得利、靠什么维持秩序 | 韩非、马基雅维利、马克思 |
| **M** 名辩 | 这些词到底指什么、命题是否成立 | 苏格拉底诘问、名家、分析哲学、结构主义与福柯 |
| **K** 认识 | 我能知道什么、我的认知如何被构造 | 柏拉图、亚里士多德、怀疑派、培根、笛卡尔、休谟、中观、唯识、禅宗、朱熹、王阳明、尼采、现象学、实用主义、系统论 |
| **S** 势史 | 长时段会怎样、我处在哪个相位 | 史观（司马迁/司马光）、黑格尔 |
| **C** 争胜 | 这一仗值不值得打、对手的虚实 | 孙子、博弈论 |

中国 17 套 + 西方 22 套。每套都是一张**八槽卡**：原典（精确篇目）· 代表命题 · 第一原理 · 核心范畴 · 方法 · 独到贡献 · 盲区 · 适用问句。

## 三条硬纪律

| 纪律 | 说明 |
|---|---|
| **必须出判断** | "需辩证看待""各有道理""取决于你的价值观"不算判断。每副镜都要给出该/不该、是/不是、往哪走。可以有条件，但不能没有。 |
| **必须出真冲突** | 至少一对相反且不可调和的答案，并写明分歧的前提。若所有透镜都同意，说明选镜失败——你选的是同一立场的不同说法。 |
| **禁范畴直译** | 道 ≠ God、仁 ≠ benevolence、中庸 ≠ 折中、无为 ≠ 不作为、空 ≠ 虚无、良知 ≠ conscience。译错之后整个体系会反转（详见 `references/03` 第三节 14 条陷阱）。 |

## 「先内化再看」在 AI 里是什么

原话是"先内化传统经典的思想，然后才能看待事物"。这里把它落成三个可检验的动作，而不是"通读经典"：

1. **取全八槽** —— 用某副镜前，八个字段都要读到。**八槽不齐不许用。**
2. **过范畴关** —— 按该体系的意思用词，不许对译后当等价。
3. **先认盲区** —— 用前就知道它必然看不见什么，输出里必须写出本题上漏掉的那一项。

为什么："方法"槽是唯一能把思想转成**操作**的槽；"盲区"槽是唯一能防**滥用**的槽。只取名言与范畴，得到的是引文堆砌；跳过这两槽，得到的是无法反驳的断言。

## 设计取舍（摘）

- **不内置任何经典的全文**。长段原文占上下文却无分析价值；短引 + 精确篇目让用户可自行核验，也避免诱导"检索原文"而非"用方法"。
- **不提供"最佳视角"推荐，也不做跨体系打分**。视角适用性依赖问题的具体前提；给"最佳"等于跳过前提判断。跨体系打分本身就需要一个共同尺度，而这正是本技能要防的范畴错误。
- **佛学/禅宗/阿奎那仅作分析方法，不做信仰判定**；**易传/阴阳家明确禁止占筮**，只保留"时/位/应"的结构分析。
- **不做事实核查、不做心理诊断、不替代专业决策**。要事实与条文请用检索或 `law-application`。

完整清单（含撤销条件）见 `registry/failure-fixes.md`。
